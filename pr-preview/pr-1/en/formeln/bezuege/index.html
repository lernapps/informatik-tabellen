Selin's formula breaks

You can already write formulas with cell references, for example =B3*B1. On this page you learn to copy a formula so that each reference moves along or stays fixed, whichever is right. In the group chat of class 9b it is about the waffle stall:

Selin: I wrote =B3*B1 in C3: waffles times price. Now I'll copy the formula down, so I don't have to type it four times.

Jona: Good idea. Then every hour is right.

Mia: Wait. What is actually in C4 after copying?

Exercise

C3 holds =B3*B1. Selin copies the formula one row down to C4. What do you think: which formula is then in C4?

  • =B4*B2 right answer

    Both references slide one row down, B1 too. So C4 reads from B2, and B2 holds text.

  • =B3*B1

    Then the formula would stay the same. But a normal reference moves along when you copy it.

  • =B4*B1

    That would be the right sum, but it is not how the sheet copies: it moves every reference, B1 too.

Move along or stay fixed

A reference like B3 really remembers a way: “one column to the left, in my row”. When you copy the formula, it goes the same way from its new cell. That is right for B3: each row should take its own number sold. It is wrong for B1: the price is only in one place, B1.

relative reference

A cell reference without $, for example B3. When you copy it, it moves along by as many columns and rows as the formula.

absolute reference

A cell reference with $ before the column and the row, for example $B$1. When you copy it, it stays the same. The $ has nothing to do with money.

Selin now writes =B3*$B$1 in C3. Copy the formula and select C5. The dashed arrow with $ always points to B1.

The same waffle stall. C3 holds =B3*$B$1, which gives 45. Copied to C4 to C6: C4 =B4*$B$1 gives 62.5, C5 =B5*$B$1 gives 77.5, C6 =B6*$B$1 gives 30. The reference to B3 moves along, $B$1 stays fixed.

The $ can also stand before just one part. Then the reference is mixed: in B$1 row 1 stays fixed and the column moves. In $B1 column B stays fixed and the row moves. The table shows what happens when you copy from B2.

Exercise

A formula holds the reference D$4. What stays fixed when you copy it?

  • only row 4 right answer

    The $ stands before the 4. It keeps the row fixed, and column D moves.

  • only column D

    For a fixed column the dollar sign would have to stand before the D: $D4.

  • column and row

    That would need one $ before the D and one before the 4.

  • nothing

    The $ always keeps the part fixed that it stands before.

A dollar sign keeps exactly the part fixed that it stands before. D$4 is a mixed reference.
